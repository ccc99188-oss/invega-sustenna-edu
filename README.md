# 認識善思達長效針

給病人看的精神科長效針劑（paliperidone palmitate，Invega Sustenna）衛教網頁，目的是增加病人的理解、減少擔憂。

- 病人衛教：劑量與緩慢釋放、減少口服藥、打針流程、副作用、常見問題、下次打針日期小工具
- 專業人員參考：藥物動力學數據、臨床實證與參考文獻（頁面最下方的按鍵）

## 檔案

- `index.html`：網頁原始內容（片段，不含 `<html>`／`<head>`）
- `build.mjs`：把 `index.html` 包成完整的 HTML，輸出到 `docs/index.html`
- `docs/index.html`：GitHub Pages 發布的檔案，請勿直接修改

修改 `index.html` 之後執行：

```
node build.mjs
```

## 注意

本網頁為衛教說明，不能取代醫師的診療與建議。內容依據美國 FDA 核准仿單（2025 年 1 月修訂版）等資料整理，使用前請以台灣核准仿單與院內規範審閱。圖表與動畫為概念示意，不可用於劑量決策。
